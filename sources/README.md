# Source catalogues

All records below this directory are source-native, provisional and
disconnected from canonical publication by default.

- CSO 3.5: official Open University research-topic source, CC BY 4.0.
  Preserve source IRIs and predicates, including superTopicOf and contributesTo.
- Historical V1: archived user-authored ontology labels and scientific
  relationships, accompanied by known independent audit failures. Only use
  as candidates; do not assert semantic accuracy or redistribute old overlays.

The published canonical knowledge lives exclusively under knowledge/.
A search hit here is not a canonical identity or a proof premise. Use
scripts/source_coverage_search.py for an explicit source-aware lookup.
