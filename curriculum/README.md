# Curriculum overlay

This directory is reserved for reviewed mappings between external curricula and canonical knowledge.

Curriculum data answers **where knowledge is taught**. It does not define the knowledge itself.

The target model will represent only the minimum hierarchy needed to identify a provider/programme/version/node and map that node to canonical concept UUIDs.

Rules:

- curriculum records must never create duplicate provider-specific concepts;
- provider wording remains in the curriculum layer rather than leaking into canonical knowledge;
- educational stage belongs here, not in alternate concept definitions;
- no syllabus PDFs or copied source text are committed here;
- schema design should follow real mapping needs discovered during the computing corpus pilot rather than trying to normalize every educational system in advance.
